# 수용시험 범위

현재 자동시험은 결정론적 핵심 로직만 점검한다.

1. 본문과 부칙의 동명 제1조를 다르게 분류
2. 유지/수정/신설/삭제를 원문과 초안 기준으로 구별
3. 신규 제정안을 일부개정문으로 허위 표시하지 않음
4. 관련 없는 기한이 같은 숫자라도 변경 대상으로 오인하지 않음
5. 존재 여부를 검토해야 할 조문 인용 발견
6. 현행 판본은 보존하고 초안 버전만 증분

추가 수용시험 필요: 다양한 조례·행정규칙 실제 판본, 형식 다른 별표/부칙, 긴 원문, 다수 항 번호 이동, 사용자 승인·거절·원복, API 오류, 배포 경로 동작, 문서 서식 품질, 보안검증.

**자동검사와 법적 적합성 심사는 다릅니다.** 외부 판본 검증 및 법적 최종 판단은 현재 구현돼 있지 않습니다.
